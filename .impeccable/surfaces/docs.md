# Documentation surface

## Scope and mode

Mode: Read. Applies to the repository's English Markdown product, design, architecture, contributor
and operator documentation. Help maintainers understand implemented behavior, constraints and
procedures; distinguish product goals, parked proposals and verified capabilities.

## Constraints

Use descriptive headings, explicit source paths and existing Markdown conventions. Do not invent
service claims, university deployments, users, migration success or a new visual identity. These
are repository documents, not a new in-app documentation renderer. `/welcome` is parked and has
no new surface direction here.
