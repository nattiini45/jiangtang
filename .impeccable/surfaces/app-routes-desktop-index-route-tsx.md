# The operational home

Mode: Operate. Inherit the existing neutral application world, type roles and density ladder.
The home answers what needs attention before anyone configures it. Five data-filled blocks:
affected room functions, due rounds/states/confirmations, today's rooms/events, personal work,
and operational changes. No decorative metrics or general edit feed.

Start with all five; highlight affected functions. Highlighted blocks come first in DOM order,
span both desktop columns and show more rows. On the phone everything is one column. Empty
blocks stay content-sized with one sentence. Counts and full-view links expose omitted rows.
Names take the flexible width, with an ellipsis and a full accessible name when needed.
Check seventy rooms and sixteen devices in the target room, at 1280 with the sidebar open in
both languages and densities, at 1920, and on a 390-pixel phone.

Anpassen is one inline UI SDK disclosure, never a required settings visit. Each block has a
named SDK selector and explicit up/down actions; no drag-only operation. Save commits the
actor's own arrangement on the server. Cancel discards the draft, and restoring the default
still needs Save. The same layout follows the person across desktop and phone sessions.
Fault and manual-state wording must preserve the canonical function projection; a planning
gap is not a fault. Today means Europe/Berlin, including DST changes.

The curated changes full view is available to members without exposing the admin audit feed,
account details or private time records. Ticket and room links retain their device-specific
destination. The old phone capture stays available separately from the home.
The due full view includes all open rounds and due state/confirmation ends; summary caps never
hide an item without a route to its full view.
