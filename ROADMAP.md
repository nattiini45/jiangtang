# Roadmap

Jiangtang is a self-hosted workspace for an AV or facilities team. One installation serves one team. This page says what is being worked on and in which order. It changes with each milestone, and it promises no dates.

## Now

- Administration basics: managing invitations, time entries that are private by default, and an administration area with a health overview.
- Faster and safer checks for every change.

## Next

- Depth for daily work: comments, recurring tasks and events, drag-to-reschedule in the calendar, and imports from other tools.
- Settings in the interface instead of environment variables, with e-mail delivery, e-mail verification and sign-up rules.
- Versioned releases with upgrade notes.

## Later

- Guided onboarding for new teams and for screens opened the first time.
- Single sign-on through OpenID Connect.
- Switching modules on and off, and more roles and teams.
- Device monitoring through an existing monitoring engine.

## Not planned

- Serving several separate organisations from one installation. Run one installation per team.
- A built-in AI assistant. Agents connect through the MCP server (docs/MCP.md).
- Backup, restore and updates from the interface. They stay documented operator tasks (docs/BACKUP.md, docs/DEPLOY.md).
